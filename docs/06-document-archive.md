# 06. 문서 아카이브 (DOC)

결재 완료 문서 + 일반 업로드 문서 통합 보관. 모듈 코드: **DOC**

---

### DOC-001 통합 아카이브
- 두 종류 문서를 보관: ① 결재 완료/반려/회수 문서, ② 일반 업로드 문서(규정·양식·매뉴얼 등).
- **AC1**: 결재 문서와 일반 문서가 동일 아카이브에서 조회된다.

### DOC-002 결재 문서 자동 보관
- 전자결재가 처리되면(승인완료/반려/회수) 해당 문서가 아카이브에 **자동 보관**된다.
- **AC1**: 결재가 `승인완료`되면 아카이브에 자동 등록된다.
- **AC2**: 반려·회수 문서도 아카이브에 보관된다(DOC-005 공개범위 적용).

### DOC-003 분류 (폴더 + 태그)
- 문서는 하나의 폴더에 위치하며 여러 태그를 가질 수 있다.
- **AC1**: 문서는 폴더 1개에 속한다.
- **AC2**: 문서는 0개 이상의 태그를 가진다.

### DOC-004 검색 (파일명·제목)
- 파일명·제목 검색만 제공(본문 전문 검색 없음).
- **AC1**: 제목 일부로 검색하면 일치 문서가 반환된다.
- **AC2**: 본문 내용으로는 검색되지 않는다(범위 외).

### DOC-005 접근 권한 (양식별 공개 범위)
- 각 결재 양식·문서에 **공개 범위** 속성을 둔다: `전사공개` | `관여자한정`.
- 기본 매핑(1차):
  - 일반 업로드 문서, 지출결의서, 비품 신청서, 일반 품의서(승인완료) → **전사공개**.
  - 휴가·근태 신청서 → **관여자한정**(민감 양식).
  - **반려·회수 문서**(양식 불문) → **관여자한정**.
- 관여자 = 상신자 + 결재자(+ 합의자/대결·수임자) + 시스템관리자.
- 권한은 백엔드에서 강제(파일 다운로드 포함, MinIO 직접 노출 금지).
- **AC1**: 휴가·근태 문서는 비관여자 일반사용자에게 조회/다운로드가 거부된다(403).
- **AC2**: 반려·회수 문서는 비관여자에게 거부된다.
- **AC3**: 전사공개 문서는 모든 활성 사용자가 조회 가능하다.
- **AC4**: 향후 양식의 공개 범위를 코드 수정 없이 설정으로 변경 가능하다(양식 속성).

### DOC-006 버전 관리
- 같은 문서를 재업로드하면 **버전 이력을 보관**(이전 버전 조회 가능).
- 반려 문서 재상신(AP-032)으로 수정된 내용도 버전으로 남긴다.
- **AC1**: 재업로드 시 새 버전이 쌓이고 이전 버전이 조회된다.
- **AC2**: 최신 버전이 기본 표시된다.

### DOC-007 파일 접근 (백엔드 경유)
- 모든 다운로드는 백엔드가 권한 검사 후 MinIO에서 읽어 전달. presigned URL 미사용.
- **AC1**: 권한 없는 사용자의 다운로드 요청은 403이며 파일이 전달되지 않는다.

---

## 모듈화 가이드 (TDD)
- `document` 패키지. **공개범위 판정**(`문서 공개범위, 요청자, 관여자 목록 → 허용/거부`)을 순수 함수로 분리해 표 기반 테스트.
- 자동 보관은 결재 `승인완료/반려/회수` 도메인 이벤트를 구독하는 핸들러로 구현(결합도 최소화).
- 버전 관리는 (문서ID, 버전번호) 모델. 최신 버전 포인터 유지.
