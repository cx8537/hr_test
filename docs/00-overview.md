# 00. 시스템 개요

## 1. 목적
사내 업무를 통합 관리하는 웹 시스템. 전자결재, 거점(사무소) 관리, 비품 관리, 차량·회의실 예약, 문서 아카이브를 단일 플랫폼에서 제공한다. 임직원·조직·권한 데이터는 본 시스템에서 직접 관리하며 외부 HR/그룹웨어와 연동하지 않는다.

## 2. 대상 사용자 / 환경
- 사내 임직원(일반 사용자) 및 각종 관리자.
- **PC 전용**(데스크톱 브라우저). 모바일 반응형은 1차 범위 제외.

## 3. 모듈 목록
| 코드 | 모듈 | 문서 | 의존 |
|------|------|------|------|
| FND | 토대(사용자·조직·권한·인증·결재키) | 01 | — |
| AP | 전자결재 | 02 | FND |
| LOC | 거점 관리 | 03 | FND |
| AST | 비품 관리 | 04 | FND, LOC |
| RSV | 예약 관리(차량·회의실) | 05 | FND, LOC |
| DOC | 문서 아카이브 | 06 | FND, AP |
| NOTI | 알림 | 07 | 전 모듈 |
| LIFE | 상태 변화·예외 규칙 | 08 | 전 모듈 |

## 4. 요구사항 ID 체계
- 형식: `<모듈코드>-<3자리 번호>` (예: `AP-012`, `FND-003`).
- 각 요구사항은 **인수 기준(AC)**을 가지며 `AC<n>`으로 하위 번호를 붙인다(예: AP-012-AC1).
- 커밋 메시지·테스트 메서드명에 요구사항 ID를 참조한다(예: `test_AP012_병렬결재_전원승인시_다음단계진행`).

## 5. 핵심 설계 원칙(전 모듈 공통)
1. **삭제 대신 비활성화** — 사용자·부서·거점은 물리 삭제하지 않고 비활성화. 과거 데이터는 보존.
2. **비우고 닫는다** — 부서/거점을 비활성화하려면 소속(직원/자원)을 먼저 정리.
3. **신규 선택 불가, 기존 표시 유지** — 비활성 대상은 신규 입력 선택지에서 제외하되, 기존 참조는 그대로 표시.
4. **상신 시 스냅샷** — 결재선은 상신 시점에 복사·고정된다.
5. **본인 키로 서명, 키 ID 동반 기록** — 결재 서명은 항상 서명자 본인 키로. 서명마다 사용 공개키 ID를 기록.
6. **공개키·레코드는 폐기 후에도 이력 보존** — 검증·감사를 위해 무기한 보관.
7. **권한은 백엔드에서 강제** — 화면 숨김에 의존하지 않고 API 레벨에서 검사.
8. **역할로 화면을 가르되, 권한은 API가 지킨다** — 단일 앱에서 역할별로 접근 화면·메뉴를 동적 통제하되, 실제 강제는 백엔드 RBAC(역할은 매 요청 판정 → 권한 변경 즉시 반영).
9. **동시성은 자원별 전략** — 예약=EXCLUSION 제약, 결재 상태=비관적 락, 일반 편집=낙관적 잠금.

## 6. 용어집
- **상신(上申)**: 사용자가 결재 문서를 작성해 결재선에 올리는 행위.
- **결재선**: 한 문서를 승인해야 하는 결재자들의 순서·구성.
- **순차 결재**: 결재자가 한 명씩 차례로 승인.
- **병렬 결재**: 같은 단계의 여러 결재자가 동시에 처리(전원 승인 필요).
- **합의(협조)**: 결재 진행을 위해 동의가 필요한 단계. 본 시스템에서는 **차단형**(거부 시 진행 불가).
- **전결(專決)**: 특정 문서 종류를 지정된 단계에서 최종 결정(상위 단계 생략).
- **대결(代決)**: 결재자 부재 시 사전 지정된 대리인이 대신 결재(건별).
- **위임(委任)**: 결재 권한을 다른 사람에게 넘김(기간: 수동 해제까지).
- **회수**: 상신자가 진행 중 문서를 취소(아무도 승인하지 않은 경우만 가능).
- **개체 관리 비품**: 자산별 고유 관리번호로 개별 추적하는 고가품.
- **수량 관리 비품**: 품목별 수량만 관리하는 소모품/저가품.
- **거점**: 지역 사무소(본사/지점/창고 등). 비품·예약 자원의 상위 단위.
- **자원(Resource)**: 예약 대상(차량 또는 회의실).

## 7. 1차 개발 범위에서 제외(명시)
- 모바일 반응형 UI
- 연차 잔여일수 자동 차감·관리(휴가는 일수 산출까지만)
- 비품 신청 결재와 재고의 자동 연동(수동 운영)
- 외부 알림(이메일/SMS) — 시스템 내 알림함만
- 시간 단위 연차(시간차)
- 전결의 금액 조건(문서 종류 기준만)
- 문서 본문 전문 검색(파일명·제목 검색만)
